📂 SAÉ 1.5

SAÉ 1.5
Traitement de données

Projet Python orienté OpenStreetMap : récupération de données via API OSM/Overpass, production de statistiques et génération de fiches aux formats Markdown et HTML.

📅 Année : 2025-2026
👥 Travail : binôme (ou autonomie si effectif impair)
🛠️ Technologies : Python, JSON, API OSM/Overpass, Markdown
🐍 Langage : Python 3.11 (salle TP)
⏳ Rendu : déc. 2025 / janv. 2026 selon statut
📋

Description & Objectifs

Contexte du projet et compétences visées

Cette SAÉ était totalement orientée programmation et data. L'objectif : utiliser Python pour interroger la base de données cartographique OpenStreetMap. On devait récupérer des données brutes, les trier, les analyser, puis générer automatiquement des fiches de présentation au format HTML. C'était un vrai exercice de logique algorithmique, où il fallait être rigoureux pour que le script gère correctement les gros volumes d'informations.
🎯

Apprentissages Critiques mobilisés

Apprentissages critiques du référentiel BUT R&T travaillés dans ce projet

Compétences mobilisées en acquisition de données, traitement, restitution et documentation de code.

Interroger des API REST/JSON (OSM et Overpass)
Concevoir des fonctions Python documentées et réutilisables
Calculer et présenter des statistiques pertinentes
J'ai organisé mon code de manière modulaire, en créant plusieurs fonctions avec des rôles précis (requêter l'API, calculer les stats, générer le HTML). J'ai vite compris que les bases de données publiques ne sont jamais parfaites : il a fallu ajouter des sécurités dans le code pour gérer les infos manquantes sans faire planter le script.
🔧

Tâches réalisées

Ta contribution personnelle et les étapes du travail

Déroulement du projet :
1) Développement d'un script capable de convertir du texte Markdown en code HTML.
2) Création d'une fonction Python pour interroger l'API d'OpenStreetMap et récupérer un lieu précis.
3) Apprentissage du langage Overpass QL pour cibler des données sur une zone géographique entière.
4) Programmation du calcul de statistiques sur les données récoltées (moyennes, filtrage).
5) Assemblage final pour automatiser la génération des rapports web de bout en bout.
📎
